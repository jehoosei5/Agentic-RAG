SQLALCHEMY SESSIONS

A SQLAlchemy Session provides a workspace for interacting with a database.

The Session can be used to query objects, add new objects, update records, and delete records.

A common FastAPI pattern is to create a session for each request.

Example:

def get_db():
    db = SessionLocal()

    try:
        yield db
    finally:
        db.close()

The FastAPI endpoint can receive the session through dependency injection.

Example:

@app.get("/users")
def get_users(db: Session = Depends(get_db)):
    return db.query(User).all()

The session should be closed after the request completes.

Calling commit() persists pending changes to the database.

Example:

db.add(user)
db.commit()

refresh() can be used to refresh an object with values generated by the database.

Example:

db.refresh(user)

rollback() can be used when a database transaction needs to be undone.

Sessions manage database transactions and object state.

A session should generally not be treated as a permanent global database connection.

For web applications, request-scoped sessions are commonly used.
